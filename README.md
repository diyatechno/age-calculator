# 🧮 Age Calculator

A simple beginner-friendly Age Calculator built using Python.

## ✨ Features
- Takes the user's date of birth.
- Calculates the user's age.
- Displays the calculated age.

## 🛠️ Technologies Used
- Python

## ▶️ How to Run

1. Install Python.
2. Download this repository.
3. Open a terminal in the project folder.
4. Run:

```bash
python age_calculator.py
```
